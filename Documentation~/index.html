ACT 动作编辑器使用指南

用时间轴安排动画、攻击和特效的触发时机。先运行基础示例，再把动作交给你自己的角色和战斗系统。

无需第三方付费插件基础示例不需要角色素材支持自己的 Agent 辅助接入

这版负责动作编排，不附带完整角色控制器。移动按键、命中伤害、连招和敌人 AI 由你的项目提供。下方会逐项说明，不需要先读代码。

01

先跑通基础示例

第一次用 Built-in 3D 空项目。按顺序做完这四步。

安装动编

打开 Window → Package Manager，选择 Install package from tarball，选中下载的 .tgz 文件，无需解压。

单独导入示例

在 Package Manager 选择 ACT Action Editor，展开 Samples，点击 Playback and Interaction Windows → Import。这一步不能跳过。

生成基础播放场景

等待编译完成，点击顶部 工具 → ACT 示例 → 生成基础播放场景。如当前场景有改动，先按提示保存。新场景位于 Assets/ACTBasicPlayback。

点击 Unity 的 Play

看到方块上升、回落，约一秒结束。Console 会显示第 15 帧攻击事件。这是时序演示，还没有命中和扣血。

成功的标志方块动起来，Console 出现一次攻击日志，没有红色错误。重复生成会使用新目录，不覆盖旧示例。
需要重播、停止，或者试试顿帧和震屏？

保持 Unity Play 模式，选择场景中的 ActionActor。在 BasicActionLauncher 组件右上角菜单选择 Play Action 重播、Stop Action 停止。动作播放时执行 Demo Impact (Play Mode)，演示局部顿帧与震屏。

安装格式：本版提供 TGZ 和 ZIP；ZIP 解压后可在 Package Manager 从磁盘选择 package.json。两种方式选一种即可。目前没有 unitypackage 产物。

02

改一个地方，马上验证

第一次只改攻击帧，理解“时间轴 → 运行效果”的关系。

选择动作

退出 Play，打开工具 → 技能编辑器。把示例 BasicAction.asset 拖进顶部“配置”。

调整触发时机

选中 Attack 事件，把开始帧和结束帧都改成 20。点击动编顶部“保存”。

再次运行

点击 Unity 顶部 Play。Console 应变成第 20 帧攻击日志。
从零新建一个动作怎么做？
  1. 点击动编“新建”，选择 Assets 下的保存位置，填写动作名称。
  2. 点击 Animation 轨道旁的“+”，选中动画块，把示例 Bounce.anim 拖进动画引用。
  3. 开始帧设为 0，暂不裁剪。在“基本信息”将退出帧设为 30，然后保存。
  4. 选中场景 ActionActor，把 BasicActionLauncher 的 Action 改成新动作，进入 Play。
怎样预览、添加事件和撤销修改？

编辑预览时，把角色拖到动编顶部“模型”；“动作源”用于读取模型资产里的动画列表。点击时间尺选帧，再点对应轨道的“+”添加事件。添加特效或音效后要填写资源引用。使用顶部撤销／重做按钮恢复修改，最后点击“保存”。

动编里的播放是编辑预览；Unity 顶部 Play 才是实际运行。首次使用统一 30 fps 的单段动画，并明确填写退出帧。

04

接入你的角色，还差什么

先让角色播放一个动作，再逐项加入移动、伤害和 AI。

空项目：先准备最小组合

  • 一个角色，以及和它匹配的动画。
  • 一个动作配置，已经分配动画和退出帧。
  • 角色上的动画播放组件和动作播放器。
  • 一个触发入口：示例自动播放，或自己的按键。

只演示动画时，不需要先写伤害系统或角色控制器。

已有项目：保留原来的系统

  • 移动仍交给已有角色控制器。
  • 从已有输入／状态机触发动编动作。
  • 把攻击事件接到已有伤害接口。
  • 按需接入现有特效、音效和镜头系统。

避免两个脚本同时控制角色位移，或两个系统重复扣血。

具体要挂哪些组件？

只播放动画：最简单是给带 Animator 的角色添加示例 BasicActionLauncher，它会要求 ActionPlayer 和 ActionClipAnimator，再把动作拖到 Action 字段。非示例接法由你的输入脚本负责触发。

希望突进：可以使用 ActionCharacterControllerDisplacement 和 CharacterController，调整胶囊尺寸，再配置 Move 轨道。已有移动系统也可以让 Agent 编写适配器。

希望命中反馈：局部顿帧用 ActionHitStop；震屏用 ActionCameraShake，放在摄像机专用父节点上。实际命中后再触发它们。

希望产生伤害／特效：需要对应事件接收组件，并和 ActionPlayer 放在同一个对象上。如果 Animator 在角色子节点，让 Agent 做适配，不要随意移动原角色层级。示例 BasicActionReceiver 只输出日志。

05

让自己的 Agent 帮你接入

你描述结果，它读取接口、检查项目，再实现必要的连接。

  1. 把安装包根目录的 AGENTS.md 文件交给你的 Agent。也可以从 Unity 的工具 → ACT 帮助 → Agent 接入说明找到说明。
  2. 告诉它目标角色、已有控制器和你希望发生的行为。
  3. 给它项目文件访问权限；若要创建资产或验证运行，还需要可用的 Unity 执行方式。

复制这段话，改成你的目标

请先读取 ACT Action Editor 安装目录中的 AGENTS.md，以及我的项目说明。保留现有角色控制器和输入系统，把一个指定动作接入我的角色。先检查动画与组件层级，列出缺少的连接；只添加必要的适配脚本和新动作，不覆盖旧资源。完成后校验配置，说明我需要挂什么组件、已经验证了什么，以及还需要我手动测试什么。

Agent 技术说明能力清单

它能实际做什么：提供的自动化入口可以列出动作和动画资产、校验动作、新建基础动作；角色接入检查可由 Unity 内的 Agent 调用。自定义功能通过项目脚本接入。读取文档不会自动获得 Unity 控制能力，当前也没有内置聊天窗口或行为树生成器。

06

卡住时，先看这里

没有“生成基础播放场景”菜单

回到 Package Manager，选择 ACT Action Editor → Samples → Playback and Interaction Windows → Import。等待编译结束后再找菜单。如果仍没有，检查 Console 第一条红色错误。“工具 → ACT 帮助 → 使用教程”不依赖示例导入。

有攻击日志，但是不扣血／没有特效

基础示例只验证时序。攻击、特效和音效需要你自己的运行时接收逻辑；可把预期效果交给 Agent，接到现有项目系统。

模型不动，或者显示粉色

先用原始 Basic Playback 场景确认安装正常。检查动画引用、角色 Animator 和动编“模型”字段。粉色通常需要核对材质与当前渲染管线是否匹配；首次在 Built-in 模板验证。

Unity 2022 能用吗？

本版验证基线仍为 Unity 6000.3.6f1，包声明最低 Unity 6000.0。Unity 2022 尚未完成适配与实测，不应把修改版本号当成兼容验证。

如何反馈，或者请 Agent 排查？

提供完整 Unity 版本、动编版本、你执行到哪一步、Console 第一条错误以及目标角色的组件信息。使用项目副本或最小示例复现，避免直接批量改动原动作资源。

交互窗口与 Agent 编辑

导入示例后使用“工具 → ACT 示例 → 生成交互窗口场景”。新动作支持显式时间轴帧率；窗口支持 All / Any / Not 组合条件与逐条件诊断。Agent 可读取、克隆并通过摘要校验提交定点编辑。
