# ACT 动作编辑器使用教程

请双击同目录的 **index.html**，或在 Unity 点击 **工具 > ACT 帮助 > 使用教程**。HTML 可以离线阅读，是本版面向使用者的主要教程；旧版长篇代码教程已由它替代。

## 最快跑通

1. Package Manager 安装 .tgz 包。
2. 选择 ACT Action Editor，导入 Samples 中的 Playback and Interaction Windows。安装包不等于导入示例。
3. 等待编译，执行 工具 > ACT 示例 > 生成基础播放场景。
4. 点击 Unity 顶部 Play：方块上升回落，第 15 帧打印攻击日志。
5. 退出 Play，打开 工具 > 技能编辑器，选择 BasicAction，修改事件帧，保存再运行。

## 自带与需要自己准备

自带：时间轴编辑、动画播放、事件分发、校验、保存/撤销、备份迁移、基础示例、可接入的位移后端、局部顿帧和震屏组件。

自己提供或让 Agent 接入：角色模型与动画、按键/角色控制器、镜头跟随、命中与伤害、技能 CD/能量、连招规则、目标选择、敌人 AI。特效/音效等轨道的实际运行逻辑需要接收器。行为树编辑器和完整控制器不属于当前版本。

## 交给 Agent

将安装包根目录的 AGENTS.md 交给你的 Agent，说明你的目标角色和预期行为。它还需要文件访问和可用的 Unity 执行方式，才能创建资产和验证接入。技术说明放在 AgentGuide.md，不需要使用者阅读代码。

当前验证基线 Unity 6000.3.6f1；Unity 2022 尚未验证。只有 TGZ 和 ZIP 安装产物，尚未生成 unitypackage。
